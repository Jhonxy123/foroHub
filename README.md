# ForoHub - API REST con Spring Boot

ForoHub es una API RESTful construida con **Spring Boot** que permite la gestión de temas en un foro virtual.  
El proyecto sigue buenas prácticas de arquitectura, seguridad y persistencia de datos, siendo un excelente ejercicio de aprendizaje con el **Spring Framework**.

---

## 🚀 Funcionalidades principales

La API permite realizar operaciones CRUD sobre los **temas**:

- ➕ Crear un nuevo tema  
- 📄 Obtener todos los temas  
- 🔍 Obtener un tema específico por ID  
- ✏️ Actualizar un tema existente  
- ❌ Eliminar un tema  

### Funcionalidades adicionales (opcionales)
- Endpoints para gestión de **usuarios** (`/usuario`)  
- Endpoints para gestión de **respuestas** (`/respuestas`)  

---

## 🎯 Objetivos del proyecto

- Implementar una API REST con endpoints siguiendo las mejores prácticas del modelo REST.  
- Aplicar **validaciones de negocio** para garantizar integridad y seguridad.  
- Persistencia con una **base de datos relacional**.  
- Configuración de **autenticación y autorización** con Spring Security.  
- Documentación de la API con **Swagger/OpenAPI**.  

---

## 🛠️ Tecnologías utilizadas

- **Java 17+**  
- **Spring Boot 3.2.3+**  
  - Spring Web  
  - Spring Data JPA  
  - Spring Security  
  - Validation  
  - Lombok  
  - Spring Boot DevTools  
- **Maven 4+**  
- **Base de datos:** MySQL 8+ o PostgreSQL 16+  
- **Flyway** para migraciones de base de datos  
- **Swagger/OpenAPI** para documentación
